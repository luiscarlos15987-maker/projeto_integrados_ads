# Projetos integrados ADS

Material de estudo de Luis Carlos: Clínica Vida+ e CAMC, acompanhado de revisão SQL.

## Executar no VS Code

1. Instale Python 3 e abra esta pasta no VS Code.
2. No terminal: `python vida_plus/main.py`.
3. Para verificar as funções: `python -m unittest discover -s tests -v`.
4. Abra `camc/wireframe.html` no navegador para testar a avaliação em três cliques.

Somente a biblioteca padrão do Python é necessária para o programa e os testes.

## Conteúdo e limites

- `vida_plus/main.py`: cadastro, busca, listagem e estatísticas em memória.
- `tests/`: verificações de entradas, busca e estatísticas.
- `docs/`: propostas acadêmicas e diagrama UML editável em PlantUML.
- `camc/`: wireframe local sem back-end.
- `sql/`: exemplos MySQL para laboratório; ainda não executados em servidor.
- `planejamento/`: cartões de backlog em CSV para cadastro manual.

Este é um protótipo acadêmico. Use dados fictícios. Não é sistema médico em produção.
O Trello não foi criado nesta sessão: capturas de backlog e evolução devem ser reais.
As autoavaliações devem refletir a experiência do estudante.

## Entrega acadêmica

Vida+: Word obrigatório; não postar PDF. CAMC: um único Word ou PDF até 10 MB.
Ambos dependem da aplicação do Modelo do AVA. Os documentos aqui são versões de apoio
com pendências claramente registradas e não uma declaração de entrega completa.
Mantenha nome completo, RA e documentos acadêmicos pessoais fora de repositório público.
